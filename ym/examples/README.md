# Four tunes to hear it with

The pinned tunes under `ym/test` are chosen to cover the format's
features, which is not the same as choosing them to be heard. These four
are here to be played.

    ym/play.sh "ym/examples/Cuddly - main menu.ym"

Each plays under Hatari through the real 68000 player, from a file the
packer wrote. `-perf` draws the raster monitor over it, so the frame's
work and the timer ticks are visible while it runs.

| tune | what it is |
|---|---|
| `Cuddly - main menu` | The Cuddly Demos, 1989, music by Mad Max. One of the ST demos that set what the machine was taken to be capable of |
| `Dark Side of the Spoon 1` | ULM's screen music, three voices and the noise generator worked hard |
| `Amiga Demo - Overscan screen` | From the demo that answered the Amiga on its own ground |
| `Mad Max 1` | 914 bytes of YM, and the smallest file here: a whole tune in less than a kilobyte |

The tunes are the ST chiptune scene's, recorded into Arnaud Carré's YM
format and kept in the open by Grazey's collection. The repository holds
them to be measured and listened to, and claims nothing over them.
